Decision Framework

Skill 不是越多越好，而是让 Agent 长出“刚好需要”的能力。

今天笔记里最有价值的部分，不是记住每个插件叫什么，而是形成了一个判断模型：哪些能力应该常驻，哪些能力只服务某类项目，哪些因为功能重叠或价值不明显可以暂缓。

Foundation

基础维护类：先分清“让 AI 更聪明”和“让 AI 更能干”。

笔记中对基础维护类的判断很清晰：Claude Code 本身已经足够聪明，泛泛的自我改进类 skill 价值有限；真正值得全局化的是搜索这种外部信息能力。

Self-improving-agent

定位是让 Agent 自我改进，但你的判断是：对 Claude Code 这类强编码 Agent 来说，收益不明显。

暂缓价值不确定

Proactive-agent

偏主动代理能力。笔记里认为实用性不强，至少不适合作为全局基础能力优先安装。

暂缓低优先级

Mem9

给智能体增强记忆。Claude Code 不一定需要，但 OpenClaw 这类私人助理型 Agent 非常适合。

按 Agent 安装记忆增强

Tavily-search

AI 搜索器，特点是搜索噪音更低。它扩展的是外部信息获取能力，适合作为全局工具。

全局安装搜索基础设施

延展理解：聪明不是瓶颈，信息入口和任务边界才是瓶颈。

当基础模型已经足够强时，继续堆“让 AI 更聪明”的 skill 边际收益会下降；更应该优先补足搜索、记忆、执行环境、结构化输出这些明确能力。也就是说，skill 的价值不是替代模型能力，而是给模型接上工具、流程和长期上下文。

Media Stack

自媒体类：内容生产不是一个 skill，而是一条流水线。

视频、文案、PPT、图文卡片、公众号发布，各自对应不同的生产环节。选择时要看你是不是正在做内容项目，而不是把所有创作插件都全局装上。

Hyperframes

适合做 HTML 转动画视频，动效表现力强。你的判断是可以安装，但更适合用于专门的智能体或特定视频项目。

  • 适合网页转视频、动态视觉展示
  • 适合产品动效和内容视觉包装
  • 不建议作为默认全局能力

Remotion

核心思路是用 React 写视频画面、动画、字幕、转场、音频，然后渲染成 MP4、GIF 或静帧。

  • 产品介绍、发布视频、教程视频
  • 网页、数据、图表动态视频
  • 字幕、标题卡、片头片尾、旁白和背景音乐
  • 波形、频谱条、节奏动画等音频可视化
  • React / Three.js 2D 或 3D 动画
  • 批量生成参数化视频，处理素材时长和尺寸
项目安装代码生成视频

Humanize

目标是去除 AI 味道。它适合文案密集的项目，也适合某些专门处理内容润色的智能体。

  • 文章、社媒、公众号文案润色
  • 降低模板感和机器腔
  • 不需要进入所有编码型 Agent

Presentation Engine

Html-ppt 是今天笔记里的主力工具：它把 PPT 变成可编程的网页表达。

你把 Html-ppt 评价为“太重要了，适合全局安装”。它不只是生成幻灯片，而是提供主题、布局、动画、键盘运行时和演讲者模式的一整套展示系统。

36 套主题

纯 CSS 变量驱动，按 T 键实时切换。覆盖商务路演、技术分享、小红书图文、学术报告、赛博炫酷等场景。

31 种布局模板

不用从零设计，可直接复制封面、目录、图文混排、数据图表、对比、时间线、团队成员等布局块。

47 种动画能力

包含 27 种 CSS 入场动画和 20 种 Canvas 特效，比如淡入、滑入、粒子、烟花、矩阵雨、知识图谱、星空和磁力场。

键盘运行时

左右翻页、T 切主题、F 全屏、O 缩略图概览、S 演讲者模式、N 笔记抽屉，适合真实演示。

全局安装演示系统

演讲者模式是 Html-ppt 的杀手级能力。

按 S 键弹出独立窗口，包含当前页预览、下一页预览、逐字稿和计时器四个磁力卡片。每张卡片可以拖拽和调整大小，布局保存到 localStorage，翻页时预览 iframe 无刷新、无闪烁。这让 HTML 演示真正接近专业演讲控制台。

最佳场景

技术分享、Meetup 演讲、产品发布 Demo、小红书图文、在线作品集、课程课件、投资人 Pitch Deck。

不适合场景

打印成纸质材料、企业 OA 系统提交、对传统 PPT 文件格式有强约束的正式交付。

相关工具取舍

Ppt-master 适合全局安装；guizang-ppt-skill 和 fronted-slides 与 Html-ppt 功能重叠，更适合特定项目。

Creator Workbench

Baoyu-skill 是内容创作者的工作台，而不是单点工具。

它的核心不是写代码，而是把 Agent 变成一个能采集资料、处理文章、生成视觉素材、制作幻灯片并发布到社媒或公众号的内容生产助手。

资料抓取网页、YouTube、X/Twitter、微信群聊等输入源
Markdown 化清洗、整理、frontmatter、摘要、slug、中文排版
翻译整理quick / normal / refined 多模式翻译和审校润色
视觉生成封面、插图、图表、漫画、信息图、小红书卡片
HTML / PPT转换成公众号 HTML、幻灯片图片、PPTX 和 PDF
发布X、微信公众号、微博，用户最终确认发布

内容类 skills

  • baoyu-xhs-images：1-10 张小红书风格图片卡片
  • baoyu-infographic：时间线、金字塔、漏斗、思维导图、鱼骨图等信息图
  • baoyu-diagram：让 Agent 写 SVG 图示，包括流程图、时序图、架构图、类图
  • baoyu-cover-image：用 Type、Palette、Rendering、Text、Mood 控制封面
  • baoyu-slide-deck：生成幻灯片图片，并合并为 PPTX 和 PDF
  • baoyu-comic：把知识做成教育漫画
  • baoyu-article-illustrator：分析文章结构并补充插图和图解

发布类 skills

  • baoyu-post-to-x：发布 X/Twitter 帖子或长文 Article，支持图片
  • baoyu-post-to-wechat：发布到微信公众号，支持贴图和文章模式
  • baoyu-post-to-weibo：发布微博文本、图片、视频或头条文章

这说明 Baoyu 不是只做素材，而是在尝试打通从内容到发布的完整链路。

生成后端与工具

  • baoyu-image-gen：支持 OpenAI、Azure OpenAI、Google、OpenRouter、DashScope、MiniMax、即梦、豆包 Seedream、Replicate 等
  • baoyu-youtube-transcript：下载字幕、封面、翻译、章节、说话人识别
  • baoyu-url-to-markdown：用 Chrome CDP 抓取动态网页并转 Markdown
  • baoyu-format-markdown / markdown-to-html / translate / wechat-summary
  • baoyu-electron-extract：提取 Electron App 资源，偏分析工具

安装判断：它很强，但不该默认进入所有 Agent。

Baoyu-skill 覆盖面很广，适合自媒体、内容工作台、公众号生产、社媒运营、知识型 IP 等项目。对于纯编码或研究型 Agent，它会显得过重；因此更适合特定项目及特定智能体安装，不建议作为所有环境的全局默认。

Developer Stack

开发类 skill 的价值，在于把 Agent 接入真实生态。

Hugging Face 和 Superpowers 是偏基础设施的开发能力：一个连接模型与数据生态，一个增强工程流程和协作方法。

HuggingFace

官方插件，适合机器学习相关工作。你的判断是适合全局安装，因为它连接的是模型、数据集、Spaces、论文、训练和评测等核心生态。

  • 查找和比较 Hugging Face 上的模型、数据集、Spaces、论文
  • 阅读模型卡、数据集说明和论文页面并总结重点
  • 下载或上传模型、数据集、文件到 Hub
  • 用 Hugging Face CLI 管理仓库和资源
  • 搭建 Gradio demo 或 Hugging Face Space
  • 运行社区 evals，微调或训练 LLM、视觉模型
  • 使用 Transformers.js 在前端或 Node 环境跑模型
  • 管理训练任务和实验追踪
全局安装官方插件ML 生态

Superpowers

开发技能包，适合全局安装。它的意义不是某个单点能力，而是让 Agent 在计划、测试、调试、验证、代码审查等流程中更有章法。

  • 适合工程任务中的系统化规划与执行
  • 适合测试驱动、调试、验证和交付前检查
  • 适合长期作为开发 Agent 的工作方法底座

Installation Blueprint

最终安装策略：先建主干，再按项目挂载专业能力。

把所有 skill 分成三层：全局主干、项目插件、暂缓观察。这样既能保持 Agent 能力强，又不会把环境变成一团功能重叠的工具箱。

推荐全局安装

  • Tavily-search高质量搜索入口，几乎所有研究和开发任务都会用到。
  • Html-ppt演示、汇报、课程、图文表达的通用生产力工具。
  • Ppt-master传统 PPT 生成主力，和 Html-ppt 形成格式互补。
  • HuggingFace连接模型、数据、论文、训练、评测和 Spaces 的官方生态入口。
  • Superpowers开发流程和工程方法底座，适合作为编码 Agent 常驻能力。

推荐按项目安装

  • 内容项目Baoyu-skill、Humanize、Html-ppt、Ppt-master。
  • 视频项目Hyperframes、Remotion，根据 HTML 动效或 React 视频生成路线选择。
  • 私人助理Mem9 这类记忆增强能力，适合 OpenClaw 等长期陪伴型 Agent。
  • 社媒发布Baoyu 的 X、微信公众号、微博发布类 skills。
  • 暂缓观察Self-improving-agent、Proactive-agent，以及与 Html-ppt 高度重叠的 guizang-ppt-skill、fronted-slides。

一条可复用原则

如果一个 skill 提供的是“长期高频入口”，就全局安装；如果它提供的是“项目生产线”，就项目安装；如果它只是“听起来很强”，但和已有工具重叠或收益不清晰，就先不装。

今天的真正收获不是插件清单，而是建立了 Agent 能力采购标准。

下一步 1：建立全局基座

优先安装 Tavily-search、Html-ppt、Ppt-master、HuggingFace、Superpowers，形成搜索、展示、开发和模型生态的基础能力。

下一步 2：按项目建画像

为内容生产、视频生成、私人助理、机器学习等不同 Agent 建立不同 skill profile，避免一套环境包打天下。

下一步 3：记录真实使用率

每个 skill 安装后记录一次实际任务效果。一个月后按使用频率和不可替代性复盘，淘汰低价值或重叠能力。
