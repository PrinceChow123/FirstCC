新增技能

本次新学习并记录的三个技能

🌟

awesome-claude-code

参考资源

Claude Code 生态的"豆瓣"——只看不装。资源索引，精选文章、skill、hook、status line、orchestrator、工具集合。

  • 精选资源索引库
  • 覆盖 Skills、Hooks、Workflows、Tooling 等
  • 不适合全局安装，适合学习 Claude Code 文件夹
  • 提供仓库评估的 slash command
"这是 Claude Code 生态的豆瓣——只看不装，用于学习和维护 Claude Code 文件夹极佳"
🎨

taste-skill

特定项目

包含多种技能的集合，核心功能是提升 AI 生成的前端界面的"品味"——让 AI 摆脱所有"AI 默认会做的事"（slop）。

  • 设计哲学：约束即创造
  • 教 AI"不要做什么"而非"做什么"
  • 可移植封装，同时适配 Cursor、Codex、Claude Code
  • 建议在需要极强设计感的项目中尝试采用
"约束即创造——这是一套设计哲学的可移植封装"
⚡

SuperClaude

特定项目

Meta-programming configuration framework，通过"行为指令注入"和"组件编排"，把 Claude Code 从聊天工具变成结构化开发平台。

  • 行为指令注入系统
  • 组件编排能力
  • 结构化开发平台转换
  • 专门适配 Claude Code，功能过于强大
"把 Claude Code 从一个聊天工具变成结构化开发平台"

Html-ppt

本次新增了个人使用评价

主要用来生成 html-ppt 格式。本次学习新增了个人评价：

"这个技能作出的 ppt 相对来讲比较好看"

Html-ppt 技能支持 36 套主题一键切换、31 种布局模板、双层动画系统（27 种 CSS + 20 种 Canvas 特效）， 以及强大的演讲者模式（按 S 键弹出独立窗口显示逐字稿、计时器等）。

评价更新

guizang-ppt-skill

新增个人审美评价

非常火爆的 html-ppt 生成工具，用来生成 ppt。但是：

"这个生成的 skill 是那种瑞士风的，不是很好看个人觉得——除非有个人的需要"

它的功能与 html-ppt 重叠，建议适合特定项目及智能体安装，不适合全局安装。

内容调整

Baoyu-skill

描述大幅简化，保留了核心定位

之前版本有详细的功能列表介绍（如 baoyu-xhs-images、baoyu-infographic 等子技能），新版简化为：

"baoyu-skills 是一套偏'创作者工作流'的 Agent 技能包，核心不是写代码，而是把 AI Agent 变成一个能帮你采集资料、处理文章、生成图片/漫画/图表/幻灯片、发布到社媒或公众号的内容生产助手"

建议适合特定项目及智能体安装，不适合全局安装。

🎯 技能安装策略

全局安装应该控制在5 个左右最常用的核心技能，其余根据项目需求灵活选择。 Tavily-search、Html-ppt、Ppt-master、Hugging Face、Superpowers 是目前推荐的全局安装组合。

📚 持续学习心态

Claude Code 的技能生态正在快速演进，保持学习和尝试的态度很重要。 像 awesome-claude-code 这样的资源索引工具，可以帮助我们持续跟踪最新的优质技能。

🎨 设计思维崛起

taste-skill 的出现反映了 AI 生成内容的"品味"问题正在受到重视。 未来能够区分 AI 输出的差异，可能比技能本身更重要。
